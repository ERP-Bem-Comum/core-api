## ⟳ PDF já importa; o que falta é OCR de verdade — medido em 02/09/2026 contra `571a14d7`

O corpo acima diz "OCR não existe hoje → provável chrome no front (item desabilitado/honesto)".
Isso mudou pela metade.

`financial/adapters/statement-parsers/pdf-parser.ts:1-8` importa PDF por gabarito sobre **texto
nativo** (via `unpdf`). Para extrato que o banco gera digitalmente, o item de menu provavelmente já
não é chrome — vale conferir na tela antes de assumir que está morto.

O que continua faltando é OCR para extrato **digitalizado** (imagem escaneada), que é um pipeline
diferente e menor do que o corpo original supõe: só entra quando não há camada de texto.

O ADR-0056 (`ocr-port-adapter`) já define a porta, mas nenhum adapter foi implementado.
